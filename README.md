# Sleep Quality Dashboard 💤

머신러닝과 설문 데이터를 활용하여  
생활 습관이 수면의 질(Quality of Sleep)에 미치는 영향을 분석하고  
웹 대시보드로 시각화한 프로젝트입니다.

---

## 📌 Project Overview

수면의 질은 개인의 생활 패턴, 스트레스, 활동량 등과 밀접한 관련이 있습니다.  
본 프로젝트는 공개 수면·라이프스타일 데이터셋을 기반으로  
주요 요인들을 분석하고,  
사용자 설문을 통해 수면의 질을 예측하는 대시보드를 구현하는 것을 목표로 합니다.

---

## 🧠 Key Features

- 수면 관련 주요 요인 데이터 분석  
  (수면 시간, 스트레스 지수, 심박수, 활동량 등)
- 머신러닝 모델을 활용한 수면의 질 예측
- Streamlit 기반 인터랙티브 웹 대시보드
- 사용자 설문 입력을 통한 예측 결과 제공

---

## 🛠 Tech Stack

- **Python**
- **Pandas / NumPy**
- **Scikit-learn**
- **Streamlit**
- **Matplotlib / Seaborn / Plotly**

---

## 📊 Dataset

- Sleep Health and Lifestyle Dataset  
- 주요 사용 컬럼:
  - Age
  - Sleep Duration
  - Physical Activity Level
  - Stress Level
  - Heart Rate
  - Daily Steps
  - Quality of Sleep

---

Streamlit을 활용한 웹 대시보드로  
데이터 분석 결과 및 수면 질 예측 기능을 제공합니다.
